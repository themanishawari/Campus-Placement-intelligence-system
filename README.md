# Proofpoint × VESIT Quasar Placement Intelligence Platform (v5.4)

An enterprise-grade, deterministic placement analytics, talent discovery, and statutory accreditation platform engineered for **VESIT Autonomous (Vivekanand Education Society's Institute of Technology, Mumbai)** in collaboration with **Proofpoint**.

---

## 🚀 Quick Start

### Option 1: Direct File Launch (Zero Dependencies)
Open [`public/index.html`](public/index.html) in any modern web browser (Chrome, Edge, Firefox, Safari).

### Option 2: Run Built-In Production HTTP Server
```bash
npm start
# or
node server/index.js
```
Then visit **`http://localhost:3000/`**.

## 🗂️ Project Structure

```
.
├── public/                  # Deployable output (served as-is)
│   └── index.html           #   Built single-page app (generated by `npm run build`)
├── server/
│   └── index.js             # Static HTTP server with SPA fallback
├── src/
│   └── views/               # Source HTML fragment for each of the 10 screens
├── config/
│   └── tailwind.config.json # Master Tailwind theme injected at build time
├── scripts/
│   ├── build.js             # Assembles public/index.html from src/views + config
│   ├── validate.js          # Syntax + view/modal presence checks on the build
│   ├── extract-views.js     # One-time import of <main> from the raw Stitch exports
│   └── dev/                 # One-off inspection/debug helpers (see its README)
├── tests/
│   └── e2e/                 # CDP route smoke tests (see its README)
├── docs/
│   └── DESIGN.md            # Design system spec
└── reference/
    ├── stitch-exports/      # Original, untouched Stitch screen exports (code.html)
    └── merged_theme.json    # Theme analysis output
```

Source of truth is `src/views/` + `scripts/build.js` + `config/`. Never edit
`public/index.html` by hand; change the source and run `npm run build`.

## 🌟 Architecture & Unified Screens

The platform unifies all 10 specialized Stitch screens into a cohesive single-page application with instant hash routing (`#/`), shared navigation shell, deep cross-screen linking, and zero console errors.

### 🏛️ Group 1: Institutional & TPO Operations
1. **Cohort Skill Dashboard (`#/cohort-skills`)**
   - Cohort competency heatmaps across IT, CMPN, EXTC, INFT.
   - Interactive remedy assignment for weak skill topics.
   - Predictive placement early-warning queue with faculty mentorship assignment.
   - Real-time AST Rescan trigger with live synchronized audit log.

2. **Campus Drive Management & Intelligent Scheduling (`#/drive-management`)**
   - Unified conflict-free calendar view for upcoming drives (Proofpoint, Barclays, Morgan Stanley, JPMC, etc.).
   - AI Drive Ingestion & Lab/Hall allocation engine with clash detection.
   - Recruiter Outreach Campaign manager.

3. **Institutional Eligibility & Talent Discovery Console (`#/talent-discovery`)**
   - Declarative rule engine (CGPA, backlogs, AST verified code thresholds).
   - Candidate pool roster with live count indicators (142 eligible out of 807).
   - Interactive view switcher: Dual Split (5:7), Rule Engine Only, or Talent Roster Only.
   - Clicking candidates opens the deep-dive preview drawer or routes directly to full profiles.

4. **Fairness Check & Statutory Accreditation Suite (`#/fairness-accreditation`)**
   - NAAC Criterion 5.2.1 and NIRF compliance matrix.
   - Adverse Impact Ratio (AIR) demographic monitor for gender and social category equity.
   - Cryptographically verifiable SHA-256 audit ledger.
   - Export Accreditation Pack (PDF and Excel formats).

5. **Student Skill Profile (`#/skill-profile`)**

   - Diagnostic score breakdown (Machine Coding 88%, SQL 92%, System Design 78%).

   - AI Interviewer audio replay with speech waveform and telemetry.
   - AI Proctor biometric telemetry log (trust score 98.4%).

8. **Personal Learning Path & Remediation (`#/learning-path`)**
   - Sprint-based learning roadmap (Distributed Storage Engine, Raft Consensus, Kernel Tracing).
   - Interactive SQL and coding practice sandbox.
   - 1:1 Code review scheduling with alumni mentors.

9. **My Drives & Institutional Eligibility (`#/my-drives`)**
   - Live campus drives pipeline (Proofpoint, Atlassian, Goldman Sachs, Uber).
   - Filters: All Drives, High Match, Eligible, Applied.
   - Dual view modes: Kanban Cards vs Compliance Audit Table.
   - Formal placement appeal modal with proof attachment and digital affirmation.

10. **My Privacy, Consent & DPDP Policy (`#/privacy-consent`)**
    - Digital Personal Data Protection (DPDP) Act 2023 compliance center.
    - Granular consent toggles for recruiter sharing, GitHub telemetry, and AI profiling.

    - Tamper-evident immutable audit ledger.

## ⚡ Interactive Modals & Added Features

- **Interactive Code & SQL Practice Sandbox**: Code editor with test runner and live execution output.
- **Code Diff & Fix Patch Viewer**: Syntax-highlighted git diff showing optimal AST solution.
- **AI Audio Replay Modal**: Vocal pace, clarity metrics, and question transcript review.
- **AI Proctor Telemetry Log**: Biometric trust verification and anti-cheat event timeline.
- **1:1 Code Review Booking**: VESIT alumni mentor selection and calendar scheduling.
- **Placement Appeal Modal**: Evidence upload and formal T&P grievance submission.
- **DPDP Right to Erasure Dialog**: Confirmation dialog with compliance protection notices.
- **Dual Persona Switcher**: Instant switching between **TPO Dean Dr. Aris Vance** and **Student Ananya Sharma**.
- **Global Toast System**: Floating status alerts for downloads, saves, submissions, and filters.
